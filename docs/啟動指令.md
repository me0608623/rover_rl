# rover_rl 啟動指令速查

> 所有 alias 定義在 `~/.bashrc`。**新開終端**或 `source ~/.bashrc` 後生效。
> 環境（zenoh RMW + DOMAIN 55）由各 alias 自動 source，或 `cd ~/rover_rl` 自動載入。
> 最後更新：2026-06-04

## 一覽表

| 指令 | 啟動 | 給誰 / 備註 |
|---|---|---|
| `ndt` | **只** NDT 定位（map_loader+downsample+tf_static+localizer） | 單獨開定位用 |
| `ndt_stop` | 停 NDT | |
| `deploy_rl` | 完整棧 deploy_full（**含 NDT**+policy+routing+costmap+MOT+bev），前景滾動 log | 任何 shell / Claude |
| `deploy_rl_shell` | 完整棧背景 + 前景繁中 TUI 儀表板 | 人在真實終端機（需 TTY） |
| `deploy_rl_stop` | 停整個 rover_rl 棧 | |
| `deploy_full_stop` | **徹底停**：deploy_full 棧 + NDT(含 standalone) + LV-DOT + 清殭屍，報殘留數 | 最保險的全停 ⭐ |
| `lv-dot` / `lvdot` | **只** LV-DOT 動態偵測（LiDAR+相機融合，YOLO 走 GPU） | 任何 shell |
| `lv-dot_stop` / `lvdot_stop` | 停 LV-DOT | |
| `deploy_all` | **一鍵**：deploy_full（含 NDT）+ LV-DOT 一起背景啟動 | 全自動 |
| `deploy_all_stop` | 停 全部（棧 + LV-DOT） | |

## ⚠️ 重要：NDT 不要重複啟動
`deploy_rl` / `deploy_all` **已內含 NDT**。
- 要「整套一起」→ 直接 `deploy_all`（或 `deploy_rl`），**不要**再另外 `ndt`。
- 只想單獨測 NDT → 用 `ndt`（此時別開 deploy_rl/deploy_all，否則雙啟 NDT 衝突）。

## ⚠️ 安全：initial_mode 預設 nav（車會動）
`deploy_rl` / `deploy_all` 的 `deploy_full` 預設 `initial_mode:=nav`：
給完 initialpose、NDT 收斂後 **policy 會發 cmd_vel、車會動**。

- 第一次 / 靜態確認：加 `initial_mode:=idle`
  ```bash
  deploy_all initial_mode:=idle
  ```
- 要動車：架空 / 遙控待命，再用預設或 `initial_mode:=nav`。

## 典型流程

### A. 一鍵全啟（最簡）
```bash
deploy_all initial_mode:=idle      # 完整棧 + LV-DOT，車先不動
# → RViz 用「2D Pose Estimate」給 initialpose，等 /ndt_pose 收斂
# → 確認 OK 後切 nav：
ros2 topic pub --once /rover_rl_policy/mode std_msgs/String "data: 'nav'"
```

### B. NDT 單獨 + 棧不含 NDT（已支援 enable_ndt）
```bash
ndt                                            # 1. 只起 NDT，RViz 給 initialpose 收斂
# 另一個終端：
deploy_rl enable_ndt:=false initial_mode:=idle # 2. 棧不啟內建 NDT → 不衝突
lv-dot                                         # 3. (可選) LV-DOT
```
> `deploy_full` 已加 `enable_ndt`（預設 true）。設 `enable_ndt:=false` 就不啟內建 NDT，
> 改用單獨的 `ndt`。`deploy_all` 同樣吃 `enable_ndt:=false`。

### C. 只跑感知（不要 policy 控車）
```bash
ndt        # 定位
lv-dot     # 動態偵測（LiDAR+相機，YOLO GPU）
```

## 驗證指令
```bash
ros2 topic hz /ndt_pose                              # NDT 收斂(~10Hz)
ros2 run tf2_ros tf2_echo map odom                   # map→odom TF(收斂證據)
ros2 topic echo /rover_rl_policy/status --once       # policy 狀態 JSON
ros2 topic hz /onboard_detector/dynamic_bboxes       # LV-DOT 動態輸出
ros2 topic echo /yolo_detector/yolo_time --once      # YOLO 推論秒數(GPU ~0.03s)
```
